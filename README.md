# Customer-Behavior-Analysis


## Project Overview

This project analyzes customer transaction data to identify customer segments, purchase patterns, retention trends, and churn risks. The objective is to provide actionable business recommendations that can improve customer engagement and revenue.

## Dataset

* Source: Kaggle Customer Behavior Analysis Dataset
* Records: 250,000 customer transactions

## Objectives

* Data Cleaning and Preprocessing
* Feature Engineering
* RFM Analysis
* Customer Segmentation using K-Means Clustering
* Purchase Pattern Analysis
* Churn Analysis
* Retention Trend Analysis
* Business Recommendations

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Jupyter Notebook

## Key Findings

* Approximately 80% of customers are active.
* Approximately 20% of customers have churned.
* High-value customers contribute significantly to overall revenue.
* At-risk customers show low purchase frequency and long inactivity periods.
* Purchase frequency strongly influences customer value.

## Customer Segments

1. High Value Customers
2. Loyal Customers
3. Average Customers
4. At-Risk Customers

## Recommendations

* Implement loyalty reward programs.
* Launch churn prevention campaigns.
* Promote top-performing product categories.
* Reduce product return rates.
* Use personalized product recommendations.
